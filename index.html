STQL - A Structured Query Toy Language and Accompanying Interpreter done in Haskell

As part of the second year of my Computer Science degree, I took modules that taught the theory of computing, programming language concepts and functional programming. One of the main courseworks that year was a group project that involved designing our own toy language. A toy language being a programming language designed with a smaller scope and a specific use case in mind).
The use case for this programming language was to modify Turtle RDF triples. Therefor, we called it Structured Turtle Query Language (STQL), a play on SQL, a language that it shared a lot of conceptual similarities with.
You can read more about this project and what I was responsible for here
